Settings

Changes take effect immediately after saving — no reload needed.

Questions

Shown on every interrupt. The "Log name" field sets a short column header for the log (defaults to the question text). "Split log here" (Yes/No questions only) breaks the log view into separate tables by the answer to this question — check it on more than one question to split by every combination actually seen. "Hide from log" drops a question's column from the log view entirely.

Flowchart: shows how questions branch off each other by their Yes/No answers, using log names. Click a question to view/edit its details. Use the "+" at the end of a branch to add a question there, or drag a question onto a "+" to move it there instead — check more than one "Show only if" box in a question's details to have it converge from multiple branches. List: a simpler flat view — drag to reorder, or use the arrows.

Interrupt Page

Controls what's shown on the interrupt page.

Always Allowed Sites

These sites are never interrupted. Enter domain names (e.g. example.com), or a file:// path to a folder (ending in /) or file to whitelist local files.

Pause Intentio

Temporarily let every site through without interrupting — for when you need to open many tabs searching for something specific and the interrupt would only slow that down. Logged with your reason and duration so it stays accountable.

Backup & Restore

Save your questions, always-allowed sites, and redirect log to a file on disk, or restore them from a previous backup. Use this before reinstalling/reunpacking the extension, or to transfer your setup to a different browser profile or device.
